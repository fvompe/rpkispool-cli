# rpkispool-cli download

Downloads the materialization archives for one day, `<date>-initstate.tar.zst` and `<date>-rpkispool.tar.zst`, and generates a filelist (`.filelist.gz`) for each. The other commands (`verify`, `coverage`) work on these files, so run `download` first.

```bash
$ rpkispool-cli download --help
usage: rpkispool-cli download [-h] [--base-url URL] [--initstate]
                              [--rpkispool] [--filelists | --no-filelists]

options:
  -h, --help            show this help message and exit
  --base-url URL        Base URL for downloads (default:
                        https://josephine.sobornost.net/rpkidata/rpkispools)
  --initstate           Download only the initstate archive
  --rpkispool           Download only the rpkispool archive
  --filelists, --no-filelists
                        Generate .filelist files after download (default: yes)
```

Example:

```bash
$ rpkispool-cli --date 20260202 download
```

## Downloading

- Files that already exist are skipped, so the command is safe to rerun.
- An interrupted download is kept as `<file>.tmp` and resumed on the next run (HTTP range request). The file is renamed only after the size matches, so a partial download never looks complete.
- A progress line is shown when stderr is a terminal.

## Filelists

A filelist is the listing of an archive (`tar -tf`), gzip-compressed, stored next to it as `<archive>.filelist.gz`. It is generated by default, use `--no-filelists` to skip it. Existing filelists are kept.

On commodity hardware, generating a filelist for a single archive takes around 15 minutes.

```bash
$ rpkispool-cli download
2026-03-05 17:51:33,469 INFO: File already exists, skipping download: work/archives/20260302-initstate.tar.zst
2026-03-05 17:51:33,470 INFO: Generating filelist for work/archives/20260302-initstate.tar.zst
2026-03-05 17:56:26,081 INFO: Filelist generated: work/archives/20260302-initstate.tar.zst.filelist.gz
2026-03-05 17:56:26,082 INFO: File already exists, skipping download: work/archives/20260302-rpkispool.tar.zst
2026-03-05 17:56:26,083 INFO: Generating filelist for work/archives/20260302-rpkispool.tar.zst
2026-03-05 18:06:23,363 INFO: Filelist generated: work/archives/20260302-rpkispool.tar.zst.filelist.gz
```

Generating filelists needs `tar` with zstd support.
